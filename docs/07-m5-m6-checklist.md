# 07 — M5/M6 worklist

The shell (M5) and packaging (M6) are the last two milestones. This file is the
orchestration checklist: every open item, its evidence, and where its rule lives.
It is kept so the work is *countable* — an item is done when its measurement is a
test or a picture, not when it looks done.

Numbering: M5 items are `S<n>`, M6 items are `P<n>`. Each item names the file
that decides it.

| # | Item | State | Rule |

| **P1** | **Game directory discovery.** `RA2_GAME_DIR` / a search, and a clear error when the game is absent. | **done — the runner and the launcher name the three files and every path they tried** | The repo ships no game files; the user supplies them. `ra2_shell::game::{find, check, REQUIRED, ENV}` (S6) accepts `RA2_GAME_DIR` first, then `local/game` above the working directory/crate, requires `RA2.cfz`, `UI/`, `Scripts/`, and its error names them. The packaged launcher (`packaging/run.sh`) adds `--game`, the XDG data directory, `game/` beside the launcher or `../game`, a source checkout's `./local/game`, and the `/usr/local`, `/usr` and `/opt` locations, then prints the three names, the whole search and both ways to supply it. Measured by `tools/smoke_package.sh`: the direct binary and `run.sh` both reject a missing game and the errors contain all three names; `the_package_ships_the_runner_and_its_required_files` re-reads the launcher against `game::REQUIRED`/`game::ENV`. |
| **P2** | **Linux build + run story.** Release binaries, a launcher, a `.desktop` file, an install/uninstall path (tarball first, AppImage/Flatpak if it earns it). | **done — portable tarball, smoke-tested; Flatpak/AppImage are marked not built** | `tools/package.sh` builds release offline and produces `dist/ra2-open-robot-arena-<version>-linux-<arch>.tar.gz` (+ `.sha256`) with `bin/{ra2-shell,ra2,ra2-render,ra2-sim,ra2-duel}`, our own `share/applications/*.desktop` and hicolor PNG/SVG icon (`tools/make_icon.py`; no game art), `run.sh`, `install.sh` (`--user`/`--system`/`--prefix`/`--uninstall`), `README.txt`, `LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE`, `THIRD_PARTY.md`. **Python decision: require system CPython 3.12**, not bundled — `readelf -d`/`ldd` show `NEEDED libpython3.12.so.1.0`, so the loader resolves it before `main()` and `--no-python` does not remove it; the launcher checks the soname and the 3.12 stdlib and reports both (`--check-python`). `tools/smoke_package.sh` unpacks the tarball into a temp dir, runs `bin/ra2-shell --route botlab --out DIR --game local/game`, asserts the seven 1280×1005 frames, compares the boot frame byte-for-byte with an independent `ra2-render --example uishot` render of `mainmenu.gib`, runs the missing-game cases and the launcher's exhibition route (3 frames). Layout, evidence, release steps, Flatpak/AppImage status and the P3 placeholder: `docs/08-packaging.md`; player instructions: README + tarball `README.txt`.
