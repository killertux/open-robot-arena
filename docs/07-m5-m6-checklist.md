# 07 — M5/M6 worklist

The shell (M5) and packaging (M6) are the last two milestones. This file is the
orchestration checklist: every item, its evidence, and where its rule lives. It
is kept so the work is *countable* — an item is done when its measurement is a
test or a picture, not when it looks done.

**State at the close of M6:** M5 is **complete** — S1–S8 have landed; S8 closed
S1's font residue (the rects were a different packing from the page), and S4's
remainder (the workshop's list and paint tools) is *named and deferred* rather
than approximated. M6 is **complete for Linux x86_64**: P1–P5 below. P3
(macOS/Windows) is *unverified by nature*: the path is documented and honest,
but no build, test or artifact exists on either platform. This is a completed
worklist, not a list of intentions.

Numbering: M5 items are `S<n>`, M6 items are `P<n>`. Each item names the file
that decides it.
